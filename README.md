# 🎮 Simon Game 2.0

An upgraded and more interactive version of my previous Simon Game project.

I rebuilt the UI to make the game feel more like a real game instead of a basic practice project, while improving the overall visual experience and interactions.

## ✨ What's Improved?

* 🎨 Modern and attractive game-like UI
* 🕹️ Interactive game controls
* 💡 Visual feedback for user actions
* ✨ Improved animations and effects
* 📱 Cleaner and more polished interface
* 🔢 Score and level display
* 🔊 Interactive game experience
* ⚡ JavaScript-based game logic

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📚 What I Practiced

Through this project, I practiced:

* DOM manipulation
* JavaScript event handling
* Game logic
* Functions and conditions
* Arrays and sequences
* CSS animations and transitions
* Interactive UI design

## 🔄 From Simple to Interactive

This project is an improved version of my earlier Simon Game.

The first version was a simple implementation created to practice HTML, CSS, and JavaScript.

In this version, I focused more on:

**UI → Interactions → Animations → User Experience**

The goal was to make the project feel closer to an actual playable game.
